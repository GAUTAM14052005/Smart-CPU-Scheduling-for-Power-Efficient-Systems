# Smart-CPU-Scheduling-for-Power-Efficient-Systems
This project implements an Energy-Aware CPU Scheduling Algorithm designed for mobile and embedded systems, where power efficiency is as important as performance. It compares the traditional Round Robin algorithm with a custom scheduling approach that intelligently assigns tasks to performance and efficiency cores.
# Project Overview
The system is built using Python and features an interactive Streamlit dashboard for real-time simulation, allowing users to adjust parameters and visualize results through Gantt charts and energy analysis graphs.

Experimental results show a significant reduction in energy consumption (around 40–45%) while maintaining efficient task execution, making it a practical solution for modern battery-powered devices.
